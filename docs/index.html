PROJECT // ROBOGLITCH

FLASH LAB_

Dein lebendiger ESP8266-Wetterroboter. Firmware direkt über USB installieren — ohne Arduino IDE.

ESP8266EX · 4 MB Flash · USB

Verbinde die Wetterstation mit dem PC, schließe serielle Monitore und wähle anschließend „Firmware installieren“. Funktioniert in Chrome/Edge über HTTPS.

Dieser Browser unterstützt Web Serial nicht. Verwende Chrome oder Edge am PC.Web Serial ist hier nicht verfügbar. Öffne die veröffentlichte HTTPS-GitHub-Pages-Seite.

Achtung: Beim Flashen wird die bisherige Firmware ersetzt. Die Geräteeinstellungen können verloren gehen. Wähle nur das passende ESP8266-Gerät.

Firmware: .bin herunterladen · Quellcode · Browser-OTA nach Einrichtung: http://roboglitch.local/update
